# Epic 4 Context: LLM 受控应答与风控兜底

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

实现基于事实卡片与对话上下文的 OpenAI 受控生成、发送前风控审核、统一模板兜底及故障步进恢复，并通过可配置的模型路由与 token 预算平衡质量和成本。买家应获得自然、合规、事实准确且不重复上一轮缓存内容的应答；生成、审核或上游服务异常均不得中断服务或让未审核内容送达买家。

## Stories

- Story 4.1: 模板兜底应答库
- Story 4.2: LLM 子图与 OpenAI 客户端
- Story 4.3: 事实卡片 Grounding 受控生成
- Story 4.4: 后置风控双审核
- Story 4.5: OpenAI 故障降级与步进恢复
- Story 4.6: 模型路由与成本护栏

## Requirements & Constraints

- 生成内容必须以事实卡片中的房源数据和对话上下文为依据，不得虚构价格、面积或学区信息；不得承诺价格可谈或学区名额，不得使用“最”“第一”等违禁词，也不得冒充经纪人。
- prompt 集中管理，统一包含事实卡片、对话上下文、生成约束三段结构。LLM 只消费指代消解后的自包含消息及其引用元数据，不得直接读取买家原始文本；内部引用标注不得出现在买家可见文本中。
- 100% 的 LLM 生成内容必须通过风控中台审核后才能发送。审核不通过、异常或超时均切换模板兜底；默认审核超时 500ms，可调范围 300–800ms。上线前压测审核通过率须 ≥95%，全量放行后仍须监控并在跌破阈值时告警。
- 模板库覆盖 9 类意图及 UNKNOWN，提供同步获取接口，统一服务管道异常、审核失败和 OpenAI 故障。PHOTO_REQUEST 须支持图片链接/相册引导及无图替代话术。模板须经业务与合规确认；转人工分支禁止使用模板兜底。
- OpenAI 返回 429、5xx 或端到端超过 1.8s 时自动降级，切换时间 <100ms；不可用期间不得向买家返回 5xx。恢复后按 10% 步进逐步切回，降级事件必须记录 Langfuse trace 并触发监控告警。
- 首 token 到达 P99 <1.5s；OpenAI 端到端 ≤1.8s，包含最多 1 次重试；审核与降级不得破坏首响端到端 P99 <3s 的预算。
- Follow-up Query 必须进入 LLM 链路，且生成文本与首次缓存响应的文本相似度须 <0.8。
- gpt-4o / gpt-4o-mini 的路由策略须配置化并支持灰度调整，可依据意图复杂度或置信度选择模型。须设置 token 预算阈值；超限时自动提高 mini 模型占比并告警，而非仅记录费用。

## Technical Decisions

- LLM 编排仅允许位于生成过滤器内部的 LangGraph 1.2.16 子图中，对外只暴露同步生成接口。路由、缓存查找、风控审核、响应组装和下发等热路径保持手写纯 Python，不依赖 LangGraph Runtime。
- 过滤器间只通过统一 Pydantic 信封通信，禁止跨过滤器直接函数调用。生成与审核模块归属 `llm/`、`filters/risk_review`；模型和 prompt 集中管理，OpenAI 接入使用 LangChain-OpenAI ≥1.6.2。
- 模型名称通过配置 alias 注入，禁止硬编码；MVP 使用 gpt-4o / gpt-4o-mini。多级替代模型降级链不属于本 Epic 范围。
- 所有过滤器异常默认 fail-closed 到模板兜底，转人工终态除外；任何路径都不得绕过审核直接下发 LLM 内容，错误响应携带 trace_id。
- Langfuse trace_id 贯穿生成、审核、降级与下发；记录审核结果、降级事件、模型选择、token 消耗和调用费用，作为质量、恢复及成本验收依据。

## Cross-Story Dependencies

- 依赖 Epic 1 的信封、过滤器编排、统一错误兜底及 Langfuse/成本追踪脚手架；Epic 1 的占位模板由本 Epic 的完整模板库替换。
- 依赖 Epic 2 的单一意图、置信度与 Follow-up Query 标记，用于生成路由和模型选择；红线意图及非文本输入的硬触发优先于 LLM 链路。
- 依赖 Epic 3 的事实卡片 schema、缓存未命中/追问绕行路由与对话摘要输入；本 Epic 不负责事实卡片写入或失效。
- 与 Epic 5 的转人工原子终态及 AI 身份约束衔接：硬触发后不得继续生成、审核或使用模板应答，Agent 文案与响应不得造成真人经纪人身份误解。
- 内部实现顺序上，模板库与 LLM 客户端是审核和故障降级的基础；受控生成依赖客户端与事实卡片；模型路由依赖客户端及成本追踪。
